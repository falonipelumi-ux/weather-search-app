# Country Search App

A simple app that lets users search for a country and see key details like capital, region, population, and flag.

## Features
- Search for a country by name
- Displays flag, capital, region, and population
- Clean UI with a background image

## Built With
- HTML
- CSS
- JavaScript (DOM manipulation, Fetch API)
- countries.dev API (free, keyless country data)

## What I Learned
- Handling API responses that return arrays instead of single objects
- Reusing patterns from a previous project (weather app) to build faster
- Styling with background images and semi-transparent cards for readability
